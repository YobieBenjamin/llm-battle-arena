Connections

API access is separate from chat subscriptions. Usage may be billed by each provider. Leave a key blank to keep it.

One question. Three answers.

  1. Just looking? Choose Sample and click Show sample. These are written examples, so there is no setup or charge.
  2. Ready for real answers? Open Connections. Paste your Claude, OpenAI, and Gemini API keys, then Save connections. You can start with just one provider.
  3. Ask anything. Choose Live API, type a question, and click Compare. Each answer appears independently.
  4. Play with it. Try a silly poem, a tricky riddle, or three takes on a travel plan. Use Stop, Retry, Copy answer, or Export Markdown.

API keys are different from chat subscriptions. Providers may charge for usage. Keys stay encrypted on this computer. No app account is needed.

No API keys? Choose Website assist: click Prepare comparison, use Open on each card, submit the copied prompt yourself, and paste the answers back.

A small Y badge means the answer contains a complete, labeled file/code block. Hover over Y to preview, click Y to keep it open, and click it again to hide it. HTML/SVG previews do not run scripts or load the internet. Source files display as text; Save file lets you keep one. Saved HTML can run scripts in an external browser.

Tiny counters show Q (question), A (visible answer estimate), and R (reported reasoning or — when unknown). A always uses the same estimator across providers. Hover for raw provider usage. These are not prices.

Answers format headings, lists, tables and code. In Website assist, use Read formatted after pasting. History keeps your last 50 comparisons locally as plain text; reopen or delete them with the History button. Reopening sends no API requests. Export anything you want to keep longer.

For a blind battle, choose Live API, include at least two cards and check Blind battle. Names and models are shuffled and hidden until you pick a winner or reveal without voting. Wins stay local. Answers can still identify themselves. Connections offers direct keys or one OpenRouter key; OpenRouter receives and routes your requests. Check key & load models fills the model menus without generating an answer.

Tip: Ctrl+Enter on Windows or Cmd+Enter on Mac starts a comparison. Each new question starts fresh; this is not a continuing chat.
