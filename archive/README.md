# OLD (DO NOT USE) — historical code

Use the `main` branch for current development and [the latest release](https://github.com/YobieBenjamin/llm-battle-arena/releases/latest) for installation.

Tags v2.1.0 through v2.4.4 are historical snapshots, retained for audit and reproducibility. Do not build or install archived tags. The previously verified v2.4.3 installer remains the temporary current download until its replacement passes all release checks; it is then archived automatically.

Old installer releases are private drafts titled **OLD (DO NOT USE)**. Git history and tags are retained rather than rewritten. GitHub can still generate source archives for historical commits: those are reference code, not supported installers.

Local historical source ZIPs and builds are in `Documents/LLM Battle Arena - OLD (DO NOT USE)`. The working repository in `Documents/GitHub/llm-battle-arena` remains active. Audit attachments are evidence, not installers, and are preserved unchanged.
